# A hufilter által biztosított szűrőlisták

## Szűrőlisták áttekintése

A hufilter két fő kategóriához biztosít listákat: teljes szintű és hálózati szintű blokkoláshoz.
A teljes szintű blokkolás nemcsak a hálózati kéréseket akadályozza meg (például a reklámok letöltését),
hanem a weboldal megjelenését és működését is módosíthatja: eltünteti az üresen maradt hirdetési helyeket,
elrejti a zavaró elemeket, és megakadályozhatja bizonyos scriptek futását is.
Ezzel szemben a hálózati szintű blokkolás csak a szerverek szintjén szűr,
így a hirdetési vagy követő domainek el sem érik az eszközt,
viszont a weboldalon megmaradhatnak az üres helyek vagy az oldal észlelheti a blokkolást.
Amennyiben lehetőség van rá, érdemes a teljes szintű listákat használni.

Bővebb információkért tekintsd át a [reklámblokkolókat bemutató oldalunkat](../../docs/adblockers/about-adblockers).

## Szűrőlisták elérhetősége

Amikor a hufilterbe új szabály kerül
(tehát [érkezik egy commit a `hufilter/hufilter` repository-ba](https://github.com/hufilter/hufilter/commits/master/)),
a frissített szűrőlisták automatikusan felkerülnek a
[`hufilter/hufilter` GitHub repository `gh-pages` branch-ére](https://github.com/hufilter/hufilter/tree/gh-pages),
onnan pedig a GitHub Pages-re.
Ezen folyamat jellegéből adódóan a listák egyidejűleg több linken keresztül is elérhetőek.

A félreértések elkerülése végett, az alább felsorolt linkek **mind ugyanazt a tartalmat szolgálják ki**,
a hufilter GitHub repository `gh-pages` branch-én található fájlokra mutatnak.
A jsDelivr egyszerűen csak alkalmas _bármilyen_ GitHub-on hosztolt tartalom kiszolgálására,
míg a `filters.hufilter.hu` domain össze van kötve a GitHub Pages-szel, ezért szolgálja ki annak a tartalmát.

Egyelőre azonban a jsDelivr linkek a lista "hivatalos" linkei, így azok használatát ajánljuk,
jelenleg azokat tekintjük a legstabilabbnak.
A jövőre vonatkozóan tervben van, hogy a `filters.hufilter.hu` linkeket fogjuk ajánlani elsődleges linkként,
azonban ha ez meg is történik, az nem fogja befolyásolni a másik két link működését,
**a lista publikálásának módja miatt mindhárom link mindig elérhető marad és nem fognak változni.**

:::note

A jelenlegi linkek 2024. július végétől vannak érvényben, bővebb információért keresd fel az alábbi GitHub issue-t:

https://github.com/hufilter/hufilter/issues/461

:::
