# About the hufilter project

Hufilter is a community project aimed at creating and maintaining an adblock filter list that removes ads, annoying elements (such as cookie notices, pop-ups, floating recommendations, etc.), and blocks various tracking tools and analytics scripts from Hungarian-language websites.

Technically, hufilter is a `.txt` format filter rule list that an ad blocker can use to block or modify certain content elements on viewed websites based on the filtering rules it contains.

Nowadays, all popular ad blockers support hufilter as a built-in language filter, so users only need to enable it in the settings (if it hasn't been enabled automatically), and they can immediately enjoy ad-free browsing of Hungarian-language websites.

## History

Hufilter was started in 2007 by [Péter Szabó][szpeter80], originally for the Mozilla Firefox and Adblock Plus combination[^1]. The project was originally hosted on his own website, and in 2014 the project moved to GitHub. Over the years, numerous volunteers have helped maintain the project.

Since 2021, the project has been managed by [scripthunter7].

In the summer of 2024, the hufilter.hu website was launched, where you can find information, tips, tricks, and other resources related to hufilter and ad blockers.
