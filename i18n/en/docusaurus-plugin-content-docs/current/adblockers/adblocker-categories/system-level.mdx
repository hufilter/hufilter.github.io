# Operating System Level Blockers

Filtering happens at the operating system level and affects all programs running on that operating system.
These solutions replace browser-installable versions, so you don't need to install separate ad blockers for each browser. System-level blockers are usually paid, but most have free trial versions
during which you can decide whether the paid version is worth it for you.

:::tip
System-level blockers also offer extra features that can further increase security, such as
DNS server replacement, firewall functionality, etc.
:::

:::note
It's possible that system-level blockers cannot effectively filter certain applications, such as
the YouTube app on Android. You can read more about the reason and solution in the
[Ad-Free YouTube on Android](../mobile-devices.mdx#ad-free-youtube-on-android) chapter.
:::
